# عمران - إدارة العقارات والمقاولات (الإصدار 3)

برنامج ويب عربي (RTL) بسيط لشركة مقاولات واستثمار عقاري. يعمل مباشرة من المتصفح بدون سيرفر ولا تثبيت. البيانات في `localStorage` وملفات العقود (PDF/صور) في `IndexedDB`، كله على جهازك.

**المستودع:** https://github.com/MrMina20/Mina

## التشغيل

افتح `index.html` بالمتصفح، أو شغّل سيرفر محلي: `python3 -m http.server 8080`.

## الوحدات الثماني

| الوحدة | الوظيفة |
|---|---|
| العملاء والعقود | بيانات العميل كاملة، الوحدة المباعة، رفع العقد الورقي PDF، جدول الأقساط، تحصيل، تذكير واتساب |
| الوحدات والعقارات | الوحدات وحالتها (تتغير لوحدها لما تسجل بيع)، سعر وتكلفة وربح |
| المشاريع | ميزانية ونسبة إنجاز وتقرير مصروف لكل مشروع |
| الخزنة | وارد وصادر فلوس فقط. تحصيل الأقساط بيتسجل فيها تلقائي |
| المخزن | وارد وصادر خامات، الرصيد بيتحسب لوحده، حد تنبيه لكل صنف |
| المقاولين والمهندسين | مقاولين ومهندسين وصنايعية بتخصصاتهم، دفعات، وملف الاتفاق PDF |
| الموردين | مستحقات الموردين (مشتريات المخزن ناقص المدفوع من الخزنة) |
| التقارير | الأقساط المتأخرة والقادمة، وارد/صادر لأي فترة، ربحية المشاريع، تصدير Excel، حاسبة الاستثمار |

## صفحة التفاصيل

الضغط على أي كارت (عميل، مقاول، مورد، مشروع، وحدة، حركة خزنة، صنف مخزن) يفتح كشف حساب كامل: كل التحصيلات أو الدفعات بتواريخها وملاحظاتها ومجاميعها، مع أزرار التعديل والحذف والإجراءات. التحصيل على دفعات جزئية مع ملاحظة لكل دفعة، وكل دفعة بتتسجل لوحدها في الخزنة وتقدر تحذفها منفردة.

## إيصال استلام نقدية

مع كل تحصيل (مقدم أو قسط) بيتعمل إيصال برقم متسلسل فيه التاريخ واسم العميل والمبلغ بالأرقام والتفقيط والمتبقي وخانات التوقيع والختم. من صفحة العميل → قسم «إيصالات الاستلام النقدية» → فتح وطباعة (أو حفظ PDF)، أو إرساله واتساب.

## التنبيهات التلقائية

مفيش حاجة تضيفها يدوي. التنبيهات بتتولد من البيانات:
- قسط متأخر على عميل.
- قسط قريب (قبل الميعاد بعدد أيام من الإعدادات، الافتراضي 7).
- صنف في المخزن وصل لحد التنبيه.
- مشروع تجاوز موعد التسليم، ومستحقات للموردين.

## هيكل الملفات

```
index.html
css/style.css
js/icons.js     الأيقونات الموحدة
js/core.js      التخزين، ملفات العقود، النسخ الاحتياطي، ترحيل بيانات الإصدار الأول
js/modules.js   تعريف الوحدات، حسابات الأقساط والمخزن والخزنة، التنبيهات، البيانات التجريبية
js/views.js     الشاشات والموجّه
js/app.js
```

## النسخ الاحتياطي

من الإعدادات: تحميل ملف JSON يشمل البيانات وملفات العقود، واسترجاعه على أي جهاز.

## الخطوات القادمة (اقتراح)

- استبدال `localStorage` بقاعدة بيانات (طبقة التخزين كلها في `S` داخل `js/core.js`).
- حسابات مستخدمين وصلاحيات.
- النشر على GitHub Pages (الموقع ثابت بالكامل).
- تعدد اللغات (الزر EN في التصميم الأصلي لم يُنفّذ).
